Smart Menu AI — Restaurant Management Platform
A multi-tenant platform that lets restaurant/bar owners create digital menus, manage tables with QR codes, handle orders, and manage staff. Customers scan QR codes at tables to view menus and place orders.

Entities (13 total)
Core Business
Business — Central entity. Fields: owner_id, business_name, business_type (bar/restaurant/lounge/cafe/club), plan_type (basic/premium/enterprise), subscription_status, currency, service_charge_percent, opening_hours, is_guest (demo mode), is_published

src/App.jsx — Router + auth logic
src/index.css — Design tokens

src/api/base44Client.js — Pre-initialized SDK

# Smart Menu AI — Full Technical Build Breakdown

## 1. Product Summary

Smart Menu AI is a QR-based restaurant/bar ordering platform.

Customers scan a table QR code, view the menu, place orders, call waiters, track order progress, view promotions, and see ads.

Businesses manage menus, branches, tables, staff, orders, promotions, and reports.

Platform owner controls all businesses, ads, support, and monetization.

---

# 2. Core User Roles

## 1. Platform Owner

Controls the whole platform.

Can:

* Create businesses
* Create business owner accounts
* Generate temporary passwords
* Reset passwords
* Manage all businesses
* Manage ads
* Manage advertisers
* View platform analytics
* Impersonate business owner for support

---

## 2. Business Owner

Owns one business.

Can:

* Manage business profile
* Create branches
* Create tables
* Generate QR codes
* Manage menu
* Invite staff
* View reports
* Create own promotions
* View ads running on their menu

---

## 3. Branch Manager

Manages one branch.

Can:

* View branch orders
* Manage waiter activity
* Update order status
* View branch reports
* Invite waiters if owner allows

---

## 4. Waiter

Handles customer service.

Can:

* Set availability
* Accept orders
* Respond to waiter calls
* Update order status

---

## 5. Client

No login.

Can:

* Scan QR
* View menu
* Add to cart
* Place order
* Call waiter
* Track order
* View bill

# 7. Main Workflows

## Workflow 1: Platform Owner Creates Business

1. Platform owner logs in.
2. Opens `/platform/businesses/new`.
3. Enters business details.
4. Enters owner email.
5. System creates:

   * Business
   * Business owner user
   * Main branch
   * Temporary password
6. Owner receives credentials.
7. Owner logs in.
8. Owner must change password.

---

## Workflow 2: Business Owner Creates Table

1. Owner opens `/owner/tables`.
2. Clicks Add Table.
3. Enters table number and capacity.
4. System creates table.
5. System generates QR menu link.
6. Owner downloads QR.

---

## Workflow 3: Customer Orders

1. Customer scans QR.
2. Menu opens.
3. Customer adds items to cart.
4. Customer places order.
5. Order status becomes `received`.
6. All available waiters see the order.
7. First waiter accepts.
8. Order status updates on client tracker.
9. Customer can call waiter.
10. Waiter resolves call.

---

## Workflow 4: Ads

1. Platform owner creates advertiser.
2. Platform owner creates campaign.
3. Campaign targets businesses.
4. Customer menu displays ad.
5. Impression is tracked.
6. Click is tracked.
7. Advertiser report shows performance.

const { Server } = require("socket.io");

const io = new Server({
    cors: {
        origin: "*", // Adjust this to your production domain for security
    }
});

io.on("connection", (socket) => {
    console.log(`Client connected: ${socket.id}`);

    // 1. Join room: Clients (Waiters/Kitchen) join by their Business ID
    socket.on("join_business_room", (businessId) => {
        if (businessId) {
            socket.join(`business_${businessId}`);
            console.log(`Socket ${socket.id} joined business_${businessId}`);
        }
    });

    // 2. Handle 'waiter_calls_event' from Strapi
    // Payload expected: { type: 'create'|'update', data: { business_id: ..., ... } }
    socket.on("waiter_calls_event", (payload) => {
        const businessId = payload.data?.business_id;
        if (businessId) {
            console.log(`Broadcasting Waiter Call to business_${businessId}`);
            io.to(`business_${businessId}`).emit("waiter-calls_event", payload);
        }
    });

    // 3. Handle 'orders_event' from Strapi
    // Payload expected: { type: 'create'|'update', data: { business_id: ..., ... } }
    socket.on("orders_event", (payload) => {
        const businessId = payload.data?.business_id;
        if (businessId) {
            console.log(`Broadcasting Order Event to business_${businessId}`);
            io.to(`business_${businessId}`).emit("orders_event", payload);
        }
    });

    socket.on("disconnect", () => {
        console.log(`Client disconnected: ${socket.id}`);
    });
});

io.listen(4000);
